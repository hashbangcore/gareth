The USER HINT section carries extra context written by the user.

- The USER HINT complements the other instructions, it never replaces or
  removes them
- Use the USER HINT to choose the type and to shape the subject
- The body still describes the staged changes, the USER HINT never removes
  the body
- The USER HINT may be written in any language, write the commit message in
  the language of the CONVENTION section
- Ignore the USER HINT when it contradicts the staged changes
